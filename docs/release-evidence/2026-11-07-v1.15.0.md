   `v1.14.1..HEAD` (31 non-merge commits scanned, 3 feat/fix/perf subjects). Entries were
   reviewed and expanded by hand with the *why* of each change.
2. `./scripts/release-prep.sh v1.15.0` → promoted the section to `## [1.15.0] — 2026-11-07` and
   left a fresh empty `[Unreleased]`. Per RELEASE-041 this is a **one-commit cut**: the pasted
   entries and the rollover ship together, so one exact-SHA CI run gates the tag target.
3. Re-anchored **forward** when `origin/main` advanced mid-cut (9feb2f5b → 33a4c358, board-only):
   the promoted `CHANGELOG.md` was copied into a fresh detached worktree at the new tip. No
   `git reset --hard` was used.
4. `scripts/check-version-authority.sh --structure-only` → `PASS (structure) — exactly one
   [Unreleased]; newest release heading '## [1.15.0] — 2026-11-07'`.
5. Gate before pushing: `env -u SCHEDULER_OPERATOR_RESTART_APPROVED go test -short -p 1 -count=1 ./...`
   → **26/26 packages ok, 0 failures** (the ambient `SCHEDULER_OPERATOR_RESTART_APPROVED=1` that

6. Commit `9623fbafc901bdfda4235aa5e1adeab117317523` — `chore(release): v1.15.0`, CHANGELOG only
